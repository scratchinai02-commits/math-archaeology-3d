# /start_session

1. 讀 `AGENTS.md`（開發規則、分層、施工進度）。
2. 讀 `docs/WORKLOG.md` 的「目前狀態」與「下一步」，以及最新一筆日誌。
3. 同步程式碼：
   ```bash
   git pull --ff-only
   npm install
   npm test
   ```
   測試沒有全綠就先停下來回報，不要開始新功能。
4. 從「下一步」挑**一項**，用三到五句話說明打算怎麼做、會改哪些檔案，等使用者確認後再動手。
5. 動手時遵守 `AGENTS.md`：數學圖形一律由演算法產生（禁止圖片、GLB、Three.js 內建幾何），演算法放 `src/math/` 並寫單元測試。
